# Formatting Conventions

## Emoji System

### Page-level emojis

**Session identifiers (H1 of index files):**
- 📕 Session 1: Productivité IA
- 📗 Session 2: Data Storytelling
- 📘 Session 3: Gestion de Produit
- 📙 Session 4: Travaux Pratiques

**Topic emojis (H1 of lesson files):**
- Each lesson has a unique emoji in its H1
- Emoji must be unique within a session (no duplicates)
- Examples: 💭 (concept), 🎧 (audio/passive), 🚀 (delivery), 📐 (tool), 🎙️ (speaking), 💼 (business)

### Inline emojis

| Emoji | Usage |
|-------|-------|
| ❌ / ✅ | Do / Don't prescriptive lists |
| 🟢 🟡 🔴 | Complexity or status scale |
| ⭐️ | Impact or quality ranking |
| 💡 | Insight or tip |
| ⚠️ | Warning or caution |
| 🔗 | External link reference |
| ✍️ | Activity or exercise |

### Where NOT to use emojis
- H2 section headers (bold text only)
- YAML frontmatter
- External link text
- "Pour aller plus loin" resource titles

## Text Formatting

**Bold (`**text**`):**
- Core concepts on first appearance in a section
- Section labels: "**Objectif :**", "**Mon conseil :**"
- Never for entire sentences

**Numbered lists:**
- Sequential steps: "Étape A :", "Étape B :" or "1.", "2.", "3."
- Processes that must follow an order

**Bullet lists:**
- Non-sequential options, examples, features
- "Ce qu'il faut retenir" items
- "Pour aller plus loin" resources

**Tables:**
- Comparisons and matrices
- Use header row with separator
- Consistent column alignment

## Headings

- `#` (H1) — Page title with emoji. **Once per file.**
- `##` (H2) — Major sections: Objectif, La méthode, Ce qu'il faut retenir, Pour aller plus loin
- `###` (H3) — Subsections within methodology. Use sparingly.
- Never skip heading levels (no H1 → H3)

## Links

- **Internal assets:** `../../assets/images/<name>.png` (relative)
- **Internal pages:** `../01-productivite-ia/apprendre-maitriser-concepts.md` (relative)
- **External:** `[Descriptive text](https://url)` — never bare URLs
- **Resources:** `[Title](url) — brief description of what the student will find`

## French Typography

- Space before `:` `!` `?` `;` (French punctuation rules)
- Guillemets « » for quotes when appropriate (regular quotes also acceptable)
- Consistent use of "IA" (not "AI")
- "data scientist" in lowercase (unless starting a sentence)
- Accents required: é, è, ê, à, ù, ç, etc.
