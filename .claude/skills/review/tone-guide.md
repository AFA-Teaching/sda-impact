# Tone & Voice Guide

## The Instructor's Voice

The author writes as a **practical mentor** — someone who uses these tools daily and shares real experience. This is NOT academic writing. It's a senior professional speaking candidly to students.

### Key characteristics

**First person presence:**
- "Je" for personal anecdotes: "J'utilise l'IA dans absolument chacune de mes activités"
- "Mon conseil:" for recommendations
- "Mon usage perso:" for workflow examples
- "Pour être honnête avec vous..." for transparency
- Every page should have at least one moment where the instructor's voice comes through personally

**Addressing students:**
- "vous" (formal but warm)
- Direct instructions: "Allez dans...", "Cliquez sur...", "Rédigez..."
- Motivational: "Vous verrez que...", "Vous allez découvrir..."

**Pedagogical transparency:**
- Always explain WHY before HOW
- Acknowledge counterintuitive ideas: "Le paradoxe:", "⚠️ Remarque"
- Name what students will encounter: "Vous entendrez parler de...", "Vous verrez souvent..."
- Admit limitations honestly: "Je n'avais pas le temps de tout relire ligne par ligne"

## Content Flow Pattern

Every major concept follows this progression:

```
1. PROBLÈME / SCÉNARIO
   → Concrete situation the student can relate to
   "Vous devez présenter vos résultats au comité de direction..."

2. CONTEXTE
   → Why this matters, what's at stake
   "Sans structure claire, votre message technique sera perdu..."

3. SOLUTION / MÉTHODE
   → Step-by-step actionable approach
   "Étape A: ...", "Étape B: ..."

4. POURQUOI ÇA MARCHE
   → Reinforce the learning with reasoning
   "Cette approche fonctionne parce que..."
```

## Autonomous Readability Checklist

Since students read without an instructor:

- **No classroom references:** Replace "comme on a vu ensemble" → "comme expliqué dans [la fiche X](lien)"
- **No implicit knowledge:** If a tool or concept is mentioned, either explain it or link to where it's explained
- **Self-contained exercises:** Include all context needed — don't assume the student attended a class
- **Clear transitions:** Each section should logically follow the previous one
- **Definitions inline:** "RAG (Retrieval Augmented Generation) — une technique qui..."

## Red Flags to Fix

| Problem | Fix |
|---------|-----|
| Overly academic/formal | Make conversational, add "Mon conseil:" |
| Concept without "why" | Add a scenario or motivation paragraph |
| Unexplained jargon | Define inline on first use |
| Theory without example | Add a concrete scenario |
| Too brief for self-study | Expand with context, examples, transitions |
| Classroom-dependent phrasing | Rewrite to be self-contained |
| No personal voice on the page | Add at least one "Je..." or "Mon..." moment |
