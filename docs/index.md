# Impact data scientist

**Objectif :** Maîtriser les compétences transversales soft skills et product skills qui feront la différence entre un bon data scientist technique et un excellent data scientist impactant.

**Pourquoi ce cours ?**  
Dans votre cursus, vous apprenez l'excellence technique (Python, SQL, Machine Learning, Cloud...). Ce module est complémentaire : il se concentre sur l'environnement de votre travail.

Savoir coder est indispensable. Savoir apprendre, communiquer, et transformer ce code en valeur produit est ce qui boostera votre carrière.

**Le programme : 4 sessions pour se transformer**  
Nous allons aborder quatre thèmes progressifs, toujours appliqués au contexte Data & IA.

[📕Session 1 : Productivité IA](sessions/01-productivite-ia/index.md)  
L'objectif : Devenir un étudiant (et futur pro) "augmenté".  
Nous utiliserons l'IA (Gemini) non pas comme une fin en soi, mais comme un levier pour :

- Apprendre à apprendre : Maîtriser des concepts complexes rapidement.  
- Coder mieux : Utiliser l'IA comme tuteur de code (sans tricher).  
- Carrière : Hacker sa recherche d'emploi et ses entretiens.

[📗Session 2 : Data storytelling](sessions/02-data-storytelling/index.md)  
L'objectif : Valoriser votre travail technique.  
Un modèle performant ne sert à rien si personne ne le comprend.

- Académique : Réussir vos soutenances de projets avec des slides pros.  
- Professionnel : Adapter son discours (vulgarisation), structurer un récit (storytelling) et convaincre des décideurs.

[📘Session 3 : Gestion de produit](sessions/03-gestion-produit/index.md)  
L'objectif : Comprendre le pourquoi avant le comment.  
Vous ne coderez pas dans le vide. Vous apprendrez à :

- S'organiser : méthodes agiles, Scrum, rituels.  
- Prioriser : Comprendre la stratégie d'entreprise (OKR) et les besoins utilisateurs (discovery).  
- Collaborer : Travailler avec des PMs, designers et le business.

[📙Session 4 : Travaux pratiques](sessions/04-travaux-pratiques/index.md)  
L'objectif : Passer de la théorie à la pratique.  
Une session intensive de 2h30 pour :

- Prototyper : Créer une application fonctionnelle wow en un temps record grâce à l'IA.  
- Pitcher : Présenter et défendre son projet comme en entreprise.
