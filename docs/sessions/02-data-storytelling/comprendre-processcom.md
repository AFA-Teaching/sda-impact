# 📡 Comprendre le Process Communication (PCM)

**Objectif :** Décoder la personnalité de vos interlocuteurs pour adapter votre discours à leur fréquence et éviter les malentendus, transformant ainsi la diversité des profils en levier de performance.

**Le principe : Nous émettons sur des fréquences différentes**  
D'après Taibi Kahler (NASA). Nous avons tous les 6 profils en nous, mais nous avons une Base (langue maternelle) et une Phase (motivation actuelle).

- Le problème : Si vous (Profil "Logique") parlez "Faits" à quelqu'un qui parle "Émotion", le message ne passe pas. C'est comme parler Chinois à un Espagnol.  
- La solution : Identifiez le profil et changez de canal.

**Le décodeur : Les 6 profils**

1\. Le travaillomane (Thinker) - "Je pense"  
Qui ? Souvent vous (data scientists), DSI, Financiers.  
Besoin : Faits, structure, logique.  
Le repérer : Toujours à l'heure, bureau rangé, questions sur le "Comment/Quand/Quoi".  
Comment lui parler (canal informatif) : Soyez factuel et précis.  
Phrase magique : "Les données indiquent une hausse de 5%. Voici le plan en 3 étapes."  
À éviter : Le flou, l'improvisation.

2\. Le persévérant (Persister) - "Je crois / Mon opinion"  
Qui ? Managers, Fondateurs.  
Besoin : Opinions, valeurs, respect, confiance.  
Le repérer : Utilise les mots "Principes", "Éthique", "Engagement". Débat beaucoup.  
Comment lui parler (canal interrogatif) : Demandez son avis.  
Phrase magique : "J'aimerais votre opinion sur cette approche. Est-ce que cela respecte nos standards ?"  
À éviter : Être léger sur les valeurs.

3\. Le promoteur (Promoter) - "On y va / Action"  
Qui ? Commerciaux, Entrepreneurs.  
Besoin : Action, Résultats immédiats, challenge.  
Le repérer : Coupe la parole, énergique, veut l'essentiel ("Bottom line").  
Comment lui parler (canal directif) : Soyez punchy. Commencez par la conclusion.  
Phrase magique : "On a une opportunité à 1M€. Go ou No Go ?"  
À éviter : Les longues explications techniques (il décroche en 30 secondes).

4\. L'empathique (Harmonizer) - "Je ressens"  
Qui ? RH, communication, ou le collègue "ciment" de l'équipe.  
Besoin : Être apprécié pour qui il est, ambiance chaleureuse.  
Le repérer : Souriant, offre du café, demande vraiment "comment ça va".  
Comment lui parler (canal nourricier) : Commencez par l'humain.  
Phrase magique : "Je suis content de te voir. Merci pour ton aide précieuse, l'équipe adore bosser avec toi."  
À éviter : La froideur, l'agressivité.

5\. Le rebelle (Rebel) - "J'aime / J'aime pas"  
Qui ? Créatifs, innovateurs.  
Besoin : Ludique, spontanéité, contact.  
Le repérer : Habillé original, blagues, soupire, réagit par "J'adore" ou "C'est nul".  
Comment lui parler (canal émotif/ludique) : Soyez décalé, faites de l'humour.  
Phrase magique : "C'est un truc de dingue, ça va tout casser. T'en penses quoi ?"  
À éviter : "Il faut faire ça, c'est la procédure." (Il se braque).

6\. Le rêveur (Imaginer) - "..." (Silence)  
Qui ? R&D pure, chercheurs.  
Besoin : Solitude, espace pour imaginer.  
Le repérer : Ne parle pas en réunion, air introspectif.  
Comment lui parler (canal directif calme) : Instructions claires, donnez-lui du temps.  
Phrase magique : "Prends le temps d'analyser ce fichier. Dis-moi demain ce que tu as trouvé."  
À éviter : Le forcer à brainstormer en groupe bruyant.

**Tactiques de communication**

Le scan des 30 premières secondes  
Analysez l'entrée en réunion :

- "Bonjour tout le monde, comment allez-vous ?" (Sourire) → Empathique.  
- "Bon, on a peu de temps, on attaque." → Promoteur.  
- "L'ordre du jour est-il validé ?" → Travaillomane.

La présentation universelle  
Structurez vos slides pour parler à tous :

1. Titre (Promoteur) : "Gagner 1M€".  
2. Intro (Empathique) : "Une solution pour aider l'équipe".  
3. Corps (Travaillomane) : "Les données et le plan précis".  
4. Conclusion (Persévérant) : "Pourquoi c'est la bonne chose à faire (Sens)".  
5. Démos (Rebelle) : "Un truc cool à voir".

L'email caméléon

- Pour le Travaillomane : Bullet points, faits, dates.  
- Pour l'Empathique : "Salut, j'espère que tu vas bien..." (indispensable).  
- Pour le Promoteur : 3 lignes max. "Problème réglé. On lance."

Gérer le stress (Mécommunication)  
Sous stress, les traits se caricaturent.

- Le Travaillomane ne délègue plus ("Je vais le faire, vous êtes nuls").  
- Le Persévérant fait la morale ("On ne respecte plus rien").  
- Le Rebelle blâme ("C'est pas ma faute").

Action : Si vous voyez ça, revenez sur son canal de base pour l'apaiser (Donnez des faits au Travaillomane, de l'opinion au Persévérant).
