# 📐 Maîtriser Google Slides

**Objectif :** Acquérir une maîtrise fluide et efficace de Google Slides pour concevoir des supports professionnels, en libérant votre attention pour ce qui compte vraiment : la valeur de votre contenu.

**Démarrage et initialisation**  
Avant de foncer, on prépare le terrain proprement.

- Accès : Via drive.google.com → Nouveau → Google Slides.

- Le template (Gagner du temps) : Plutôt que de partir d'une page blanche, utilisez Fichier → Nouveau → À partir d'un modèle. En entreprise, c'est ici que se trouve la charte graphique officielle.

- Nommer le fichier : Cliquez sur "Présentation sans titre" en haut à gauche. Format recommandé : [Date] - [Nom du Projet] - [Type: Avancement/Final].

**La barre d'outils**  
Les 20% de fonctionnalités que vous utiliserez 80% du temps.

- Ajouter une slide intelligemment : Ne cliquez pas sur le +. Cliquez sur la petite flèche ▼ à côté. Cela ouvre la bibliothèque de mises en page ("Titre seul", "2 colonnes", etc.).  
  - Pourquoi ? Cela évite de devoir aligner vos zones de texte manuellement à la souris.

- Zone de texte (T) et formes : Pour vos annotations et schémas d'architecture (pipeline de données, flux).

- Le thème : Accessible via le bouton "Thème" (quand aucune slide n'est sélectionnée). Permet de changer les couleurs/polices de tout le document en un clic.

**Intégration de contenu riche**  
C'est ici que vous illustrez vos résultats. Menu Insertion.

- Images (vos graphes) : Insertion → Image → Importer.  
  - Conseil Data : Si vos graphes sont sur Drive (générés par un notebook), importez-les directement depuis Drive pour éviter les versions obsolètes sur votre bureau.

- Vidéos (vos démos) : Insertion → Vidéo. Idéal pour montrer un agent IA en action ou une interface Streamlit.  
  - Astuce Pro : Une fois la vidéo insérée, utilisez les "Options de format" (à droite) pour définir l'heure de début et de fin. Ne montrez pas les 30 secondes de chargement, allez droit au but.

- Numérotation (indispensable) : Insertion → Numéros de diapositives → Appliquer.  
  - Pourquoi ? Pour faciliter les questions du jury ("Question sur la slide 4" vs "Celle avec le graphe bleu").

**Collaboration et sécurité (le travail d'équipe)**  
Google Slides brille par son aspect collaboratif. Ne vous envoyez pas de fichiers par mail (version\_finale\_v2\_vrai.pptx).

- Le bouton "Partager" (haut droite) : La tour de contrôle.  
  - Éditeur : Pour vos co-équipiers (modification totale).  
  - Commentateur : Pour votre tuteur/manager (peut annoter sans casser).  
  - Lecteur : Pour une large diffusion (lecture seule).

- Commentaires : Sélectionnez un élément (ex: un chiffre douteux) → Clic droit → Commentaire (ou bulle 💬).  
  - Taguer : Utilisez @prenom pour notifier spécifiquement quelqu'un ("@Thomas, vérifie cet accuracy score stp").

- Historique des versions (le filet de sécurité) : Quelqu'un a tout effacé par erreur ?  
  - Allez dans Fichier → Historique des versions → Afficher l'historique.  
  - Remontez dans le temps et cliquez sur "Rétablir cette version".

**Le jour J : Présentation et export**

- Mode Présentateur (le cockpit) : Cliquez sur la flèche ▼ à côté de "Lire" → Mode présentateur.  
  - Vous voyez : Vos notes, le chrono, la slide suivante.  
  - Le public voit : Uniquement la slide en cours.  
  - Condition : Nécessite deux écrans (ou mode étendu lors d'une projection).

- Export PDF (la sauvegarde) : Fichier → Télécharger → Document PDF.  
  - Toujours avoir une version PDF sur une clé USB le jour de la soutenance au cas où le wifi lâche. Le PDF fige la mise en page (polices, images) pour toujours.
