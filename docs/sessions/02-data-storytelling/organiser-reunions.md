# 🗓️ Organiser des réunions

**Objectif :** Transformer les réunions en outils de décision redoutables et protéger votre temps de production en éliminant impitoyablement les rencontres sans valeur ajoutée.

**La philosophie**  
Une réunion coûte cher (Salaire x Nbre de personnes x Durée). Si rien n'en sort, c'est une perte sèche.

Identifier le type de réunion  
Ne mélangez jamais les genres.

1. Le problem solving (atelier) : On a un blocage (ex: le modèle ne converge pas).  
- Format : 3-4 personnes max. On ouvre le code, on dessine. C'est du travail.

2. La décision (Comex/SteerCo) : On présente des options (A, B, C).  
- Format : Formalisé. On sort avec une validation. Pas de débat technique.

3. L'Information (update) : Souvent inutile.  
- Règle : Si c'est juste pour dire "j'ai fait ça", annulez la réunion et envoyez un email récapitulatif.

La règle "no agenda, no attenda"

- Principe : Refusez toute invitation sans ordre du jour clair.  
- L'agenda : Ce n'est pas une liste de thèmes ("Point Data"). C'est une liste de questions à trancher ("Validation du budget Cloud vs On-Premise").

Le casting

- La règle (Jeff Bezos) : Si on ne peut pas nourrir tout le monde avec deux pizzas (6-8 personnes max), il y a trop de monde. L'intelligence collective s'effondre au-delà.  
- Les rôles : Il faut 1 décideur, 1 faiseur (Vous), 1 expert. Les autres sont des spectateurs : envoyez-leur le compte-rendu, ne les invitez pas.

**Avant : La préparation**

Le pre-read  
N'arrivez pas en réunion pour découvrir le sujet.

- Action : Envoyez le support 24h avant.  
- Tactique : Si personne n'a lu, commencez la réunion par 10 min de lecture silencieuse. Ensuite, on discute directement des blocages.

Le calibrage temporel (25/50)  
Changez vos réglages par défaut dans Outlook/Google Calendar.

- 30 min ➔ 25 min  
- 60 min ➔ 50 min  
- Pourquoi ? Pour laisser aux gens le temps de faire une pause bio, boire un verre d'eau et ne pas arriver en retard à la suivante.

Le droit de refus  
Si votre rôle n'est pas clair :

- Réponse type : "Je ne suis pas sûr de ma valeur ajoutée sur ce point. Puis-je t'envoyer mes inputs par mail à la place ?" (Vous venez de gagner 1h de code).

**Pendant : L'animation**

Le lancement GPS (30 premières secondes)  
Cadrez immédiatement pour éviter le flou.

- G (Goal) : "On est là pour décider du budget."  
- P (Process) : "On regarde les chiffres, puis on vote les options."  
- S (Stake) : "Si on ne décide pas, le projet prend 2 semaines de retard."

La discipline de fer

- No tech : "Laptops closed". Si les gens font leurs mails, ils ne servent à rien.  
- Le parking lot  : Vital pour les data scientists. Si un débat technique dérape (ex: détail de l'API) et n'intéresse pas le décideur : "Marc, point intéressant mais hors-sujet ici. Je le note au parking lot et on le règle tous les deux après."  
- Le timekeeper : Désignez quelqu'un pour surveiller l'horloge. "Il reste 10 min et on n'a pas tranché."

**Après : L'atterrissage**

Le WWW (Who Does What by When)  
On ne sort jamais sans ça.

- ❌ "On va regarder ça."  
- ✅ "Thomas (Who) m'envoie l'export (What) pour mardi 14h (When)."

Le compte-rendu flash (IDR)  
Personne ne lit les CR de 3 pages. Envoyez un email dans les 15 minutes suivant la réunion.

- I (Informations) : Ce qu'on a appris.  
- D (Décisions) : Ce qu'on a acté.  
- R (Recommandations/Actions) : La liste WWW.

**La boîte à outils**  
L'invitation (calendar)  
C'est le contrat de départ. Mettez le lien visio, les documents (pre-read) et l'objectif (GPS) directement dans l'invitation.

La prise de note collaborative (Google Doc / Confluence)

- Tactique : Projetez le document de notes sur l'écran pendant que vous écrivez.  
- Effet : Tout le monde voit "Décision : Budget validé". Si personne ne conteste en direct, c'est acté. Fini les "Ah je n'avais pas compris ça" deux jours plus tard.

Les outils d'atelier (Miro / FigJam)  
Pour les réunions de type problem solving uniquement.

- Miro / FigJam : Idéal pour les brainstormings visuels, les architectures de données ou les rétrospectives agiles.  
- Attention : Préparez le board à l'avance. Ne perdez pas 15 min à expliquer comment créer un post-it.

Le timer visuel  
Affichez un gros chronomètre sur l'écran partagé lors des brainstormings. La pression temporelle force la synthèse.
