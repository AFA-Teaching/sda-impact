# Todo

**⏱️ Étape 1 : Démarrer (10 min)**

- [ ] Ouvrez un nouveau Google Doc.  
- [ ] Copiez le template. Allez dans l'onglet [🖼️Canvas]() de ce guide, copiez tout le texte, et collez-le dans votre Google Doc.  
- [ ] Donnez le lien d'édition à tous les membres du groupe (et assurez-vous que l'accès m'est ouvert : [adam.faik.perso@gmail.com](mailto:adam.faik.perso@gmail.com)).

**🧠 Étape 2 : Définir l'hypothèse (20 min)**

- [ ] Remplissez la section "Hypothèse" du Canvas : Définissez clairement votre pari.  
- [ ] Aide IA : Si vous séchez sur la formulation, demandez à Gemini de vous aider.  
- [ ] Remplissez la section "Guide d'entretien". Préparez vos questions pour valider votre hypothèse.

**📝 Étape 3 : Rédiger des specs (10 min)**  
Maintenant, transformons vos idées en langage précis pour l'IA.

- [ ] Ouvrez [Gemini](https://gemini.google.com/).  
- [ ] Copiez votre Canvas rempli et demandez à Gemini de vous aider à rédiger des specs.  
- [ ] Analysez la réponse : Gemini va vous donner la structure du prompt système et des idées pour l'interface. Gardez ça sous le coude.

**🛠️ Étape 4 : Construire le prototype (30 min)**  
C'est le moment de construire "la vraie chose" dans Google AI Studio.

- [ ] Connectez-vous à [Google AI Studio](https://aistudio.google.com/).  
- [ ] Copiez-collez les specs de l'étape 3. Sélectionnez les composants AI dont vous avez besoin.  
- [ ] Visualisez le résultat et réalisez des itérations.  
- [ ] Faites une capture d'écran de votre interface augmentée par l'IA et collez-la dans votre Canvas (Section 4).

**🎙️ Étape 5 : Présenter le résultat (15 min)**

- [ ] Allez sur [NotebookLM](https://notebooklm.google.com/).  
- [ ] Importez votre Google Doc, celui avec le Canvas rempli et le screenshot.  
- [ ] Utilisez NotebookLM pour générer un pitch deck. Rédigez un prompt pour personnaliser cette présentation.  
- [ ] Présentez votre résultat.
